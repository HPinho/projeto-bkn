# Cq 0.1 — Contrato Executável e Especificação

Cq 0.1 é o subconjunto procedural da linguagem Cq, usado para materializar compilação estrita e preparar a auto-hospedagem (*VortexC-lite*). Ele não depende do runtime legado nem declara prematuramente ARC, classes, `Optional`, `match`, `throws` ou LLVM antes da base procedural estar sólida.

---

## Recursos Implementados e Validados (Fase A)

- **Módulos e Imports**:
  - `module caminho::qualificado;`
  - `import caminho::qualificado::*;` (resolução em DAG topológico com detecção de ciclo).
- **Tipos de Dados**:
  - Primitivos fixos: `u8`, `u16`, `u32`, `u64`, `usize`, `i8`, `i16`, `i32`, `i64`, `isize`, `f32`, `f64`, `bool`, `void`.
  - **Arrays Fixos**: `[T; N]` (alocação contígua em stack ou structs).
  - **Ponteiros**: `*mut T` e `*const T`.
  - **Casts Explícitos**: `expr as Type`.
  - **Literais**: Números decimais/hexadecimais (`0x...`), strings (`"..."`), caracteres (`'c'`), booleanos (`true`, `false`) e `null`.
- **Classes e Orientação a Objetos**:
  - `[pub] class Nome { campo: Tipo; [pub] fn metodo(self: *const Nome, ...) -> Retorno { ... } }`
  - Chamadas de método: `obj.metodo(...)` (com passagem por endereço `&obj` automática quando o método espera `self: *const/mut Nome`).
  - Métodos associados / Construtores: `Classe::novo(...)` mapeado para `Classe_novo(...)`.
- **Estruturas de Dados Procedurais**:
  - `[pub] struct Nome { campo: Tipo; }` com atributos `@repr(C)`, `@packed`.
  - `[pub] enum Nome { Variante1, Variante2 = 10 }` e acesso `Nome::Variante1`.
- **Módulos Core e Gerenciamento de Memória**:
  - `core::arc`: Contagem de referências soberana (`ArcHeader`, `SharedCounter`, `arc_init`, `arc_retain`, `arc_release`, `arc_count`).
  - `core::option`: Padrão de segurança contra ponteiros nulos (`OptionU32`, `OptionPtr`, `some`, `none`, `is_some`, `unwrap_or`).
  - `core::result`: Tratamento explícito e seguro de erros (`ResultU32`, `ResultCode`, `ok`, `err`, `is_ok`, `is_err`, `unwrap_or`).
- **Globais e Constantes**:
  - `[pub] const NOME: Tipo = valor;`
  - `[pub] static [mut] NOME: Tipo = valor;`
- **Funções e Controle de Acesso**:
  - `[pub] fn nome(param: Tipo) -> Retorno { ... }`
  - Atributos `@system`, `@export`, `@inline`.
- **Segurança de Memória (*Unsafe Rules*)**:
  - Desreferenciamento de ponteiros (`*ptr`, `ptr.campo`, `ptr[idx]`) e casts de ponteiros brutos exigem bloco `unsafe { ... }` ou função anotada como `@system`. Violações geram diagnósticos com linha, coluna e indicador visual `^`.
- **Fluxo e Instruções**:
  - `let [mut] var [: Tipo] = expr;`
  - `var = expr;` e `arr[idx] = expr;`
  - `if expr { ... } else if expr { ... } else { ... }`
  - `while expr { ... }`
  - `break;` e `continue;`
  - `return [expr];`
  - `unsafe { ... }`

## Comandos do Compilador

```powershell
# Checagem sintática e semântica de arquivo único
python tools/vortexc/vortexc.py cq01-check tests/fixtures/cq01_sample.cq

# Emissão de C11 para arquivo único
python tools/vortexc/vortexc.py cq01-emit-c tests/fixtures/cq01_sample.cq -o build/cq01_sample.c

# Compilação e linkedição modular de projeto Cq 0.1
python tools/vortexc/vortexc.py cq01-build bootstrap/cq01/kernel/main.cq -o build/cq01_minimal_kernel.c
```

## Verificação e Testes

A suíte executável em `tests/test_cq01_frontend.py` valida:
1. Lexer, parser e recuperação de erros com snippets visuais.
2. Tipagem, aridade e detecção de símbolos inexistentes.
3. Resolução e compilação em ordem topológica de dependências.
4. Validação estrita de regras `unsafe`.
5. Emissão e compilação real em C11 com GCC (`-std=c11 -Wall -Wextra -Werror -c`).
